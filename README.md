PROMPT PARA O LOVABLE

SITE DEMONSTRATIVO — SISTEMA INTELIGENTE DE GESTÃO E ANÁLISE DE DADOS PARA AÇOUGUES E CASAS DE CARNES

1. OBJETIVO DO PROJETO

Desenvolver um site demonstrativo profissional, moderno, responsivo e altamente persuasivo para apresentação comercial de uma solução integrada de:

ERP + Gestão Empresarial + Análise de Dados + Inteligência Gerencial + Gestão de Perdas + Gestão de Desossa + Gestão de Etiquetas e Produção

voltada especificamente para Açougues e Casas de Carnes.

Este projeto possui finalidade demonstrativa e comercial.

Não implementar, nesta etapa, toda a infraestrutura operacional de um ERP real. O objetivo é construir uma experiência visual suficientemente realista para que, durante uma apresentação comercial, o potencial cliente consiga compreender como a tecnologia pode transformar a gestão de sua empresa.

O site deverá demonstrar principalmente que o empresário pode deixar de administrar seu negócio apenas com base em faturamento, saldo bancário ou percepção pessoal e passar a administrar com base em dados, indicadores, custos, margens, perdas e lucratividade real.

2. CONCEITO CENTRAL DA APRESENTAÇÃO

A comunicação deverá ser construída em torno de quatro pilares:

CONTROLE

Conhecer exatamente o que acontece dentro da empresa.

PREVENÇÃO DE PERDAS

Identificar onde, como, quando e por que a empresa está perdendo dinheiro.

OTIMIZAÇÃO DE LUCROS

Identificar oportunidades para aumentar margens e melhorar os resultados.

INTELIGÊNCIA PARA DECISÕES

Transformar os dados gerados diariamente pela operação em informações gerenciais úteis para tomada de decisão.

A apresentação deverá transmitir a seguinte percepção:

Não basta saber quanto a empresa vende. É necessário saber quanto realmente sobra.
